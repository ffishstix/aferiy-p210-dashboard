# AFERIY P210 monitor

Public battery status and history, with sign-in for controls: [aferiy-p210-monitor.pages.dev](https://aferiy-p210-monitor.pages.dev). Source: [GitHub](https://github.com/ffishstix/aferiy-p210-dashboard).

The Cloudflare Pages site, D1 history database, and Windows tray program are live. The separate [collector repository](https://github.com/ffishstix/aferiy-p210-collector) supplies readings through the Worker service binding. The owner compared live input/output readings with the phone app. Real low-battery alerts and every advanced field still need validation.

See [PROJECT_PLAN.md](PROJECT_PLAN.md) for the diagram and remaining steps. No account credentials are committed to this repository.

Third-party code and protocol references are documented in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
